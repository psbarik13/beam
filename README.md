# Beam

Send a file between two devices screen to camera, through a full-screen colour grid (or QR codes). No Wi-Fi, cable, account or internet.
Files are compressed first (Word, Excel and PowerPoint often to a third). Export the codes as a PDF to print (1, 4 or 9 codes per page), PNG images or a slideshow for any screen, with a live preview; anyone with Beam can scan them or import the files. Optional password protection (AES-256).
The receiver reads part of a code as the phone moves over it, zooms in by itself when the squares are small, and reads dense printed pages from full-resolution photos (tap Photo), showing a map of what each photo read.

- **Open it:** https://psbarik13.github.io/beam/
- **Download** Beam (to run offline) or Courier (Wi-Fi folder sharing): https://psbarik13.github.io/beam/download/

On a phone, open the link and tap Send or Receive. On a computer, Beam can send straight from the downloaded `beam.html`. To receive with a webcam, run `start-beam`, which opens Beam at http://localhost so the browser allows the camera.

This repository holds the published site only. Source code lives in a private repository.
